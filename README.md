# One Room Observer

Godot 4.x MVP for observing one local-LLM resident living in one room.

Open the folder in Godot and run `Main.tscn`. The default LLM endpoint is `http://127.0.0.1:8000/v1`; connection settings are saved in `user://one_room_config.json`. If the server is unavailable, the resident waits safely and the simulation continues.

The simulation is intentionally small: no town, work, money, other NPCs, internet, OS control, or assigned goal.
